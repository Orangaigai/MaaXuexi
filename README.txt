MaaXuexi 使用说明

手动执行
1. 双击“启动MaaXuexi（无黑窗）”快捷方式，或“启动MaaXuexi.cmd”。
2. 等待控制网页和 MuMu 打开，在网页点击“执行所选任务”。
3. 在网页查看每项实际积分、运行日志和需要本人处理的提示。

控制页：http://127.0.0.1:8000/
启动入口只准备环境；手动任务由网页上的执行按钮开始。
重复打开启动入口会复用正在运行的后台。关闭网页不停止任务。
中止本轮用网页上的中止按钮；关闭后台用“停止MaaXuexi.cmd”。

每天自动执行
Windows 计划任务 MaaXuexi-Daily-0900 保留为每天北京时间 09:00。
电脑需要开机、登录当前 Windows 用户、未休眠且联网。
勾选项目后点击“保存为每天 9:00 清单”，定时按保存的清单执行。
按2026-10-17本机积分和验证记录排序（详见docs/任务积分与执行顺序-20261017.md）。登录为前置步骤，通常无验证的文章/视频/本地先做；可能验证的趣味10分、订阅2分、观点1分依次执行；模拟器上频繁验证的每日5分最后。验证分组不是永不验证或每次强制验证的保证。
执行顺序为登录、选读文章、视听学习、本地频道、趣味答题、订阅、发表观点、每日答题；只执行清单中选中的项目。
需要本人在场验收时，Run-Daily.ps1 的 -VerificationFirst 仅改变本轮顺序：登录、趣味、每日、订阅、观点在前，随后自动接续文章、视听、本地；不保存到九点清单。
文章按当前缺额分批阅读，批后核分，满分即停；不再固定累计400秒后才读分。
点选填空同样读取提示红字，只有完整且唯一的顺序匹配才直接选择，否则交给模型。
读屏保留完整宽度，只裁纯色空白边缘；重新截图像素完全相同才复用OCR。图片题结合题干与画面分流，视觉请求保留完整截图。
四项优化的实测范围与参考来源见docs/四项收尾优化与验收-20261017.md。
普通选择题的提示比较保留算式、单位分隔和上/下标，避免清洗符号导致误配；不再进入旧的宽松选择题猜测分支。
每日普通选择题需要模型时，完整单屏文字题会发送题干、全部选项和提示文字；长选项读取整屏多行内容。跨屏、含图或提示不完整时仍发送完整图片，无需另开设置。
模型对比工具为scripts/Compare-QuizModels.py，默认只校验历史样本；手动加--run才请求官方接口，不参与九点任务，也不自动换模型。说明见docs/每日文字分流与模型对比-20261018.md。
普通填空在完整题干、空位与提示可唯一对齐时直接填原文；多个独立输入框或题干不全时沿用原处理路径。
每日答题日志显示提取提示、确定答案、填写和页面响应的耗时；运行摘要分别记录截图、OCR、模型及本人等待。
每日提交的关键画面最多保存24张，可用scripts/Replay-DailyTrace.py离线检查；回放不会操作安卓或请求模型。
本轮细节见docs/提示匹配与运行诊断-20261017.md。文章保留原已读识别和本轮去重，不增加跨重启历史数据库。
已满分的项目跳过；对战首局已领取积分时按实际分数记录。
每轮首次核分重新进入积分页，防止跨天沿用旧页面。

本地频道
先读取本地频道实际积分，已满1分跳过；未满时从首页当前地区进入学习平台，随后重新核分。
地区名从首页识别，无需手填省份；图标文字粘连时只识别对应小区域，不调用模型。
首次出现定位说明时采用拒绝新增定位权限的路径，沿用App已选地区。
当前入口无法确认或未到账时记录真实结果，不反复进入凑分。
完整研究和验收见docs/积分扩展研究与验收-20261017.md。

发表观点（按正文生成，已启用）
仅在科普中国/生活百科文章下，读取正文并用DeepSeek生成8～20字的日常短评，少用抽象术语，核对原文依据后再调用模型复核。
允许原文已有的AI缩写；相关性按含义复核，不要求照搬原文字眼。不自动复制他人评论，读评论暂未作为每日必经步骤。
不临场展开时政或人物评论，不编造个人经历或绝对保证，不合格就跳过；检查仍可能漏判。
无人值守每天最多一次发表尝试；本人手动发起可补验，每轮只提交一次、满分跳过，历史记录保留。验证页面恢复后自动核分；明确的网络错误页最多点一次“重试”，不会再次点击发布。验证仍需本人处理。
发布前最多检查三篇候选文章；短评不适合就换文，不降低规则。模型服务异常则停止，不为同一篇文章反复生成；已点击发布后不再换文追加。
短评依据改为逐屏读取的全文，不再只取第一屏；合并相邻屏重复文字，确认文末后恢复篇首并再次核对同篇标题。十二屏内无法确认读完、全文超过四千字或范围不适合时换文，不拿部分正文冒充全文。模型生成和独立复核都使用同一份全文。
生成目标是围绕全文一个具体点写普通读者的友好短评，允许贴文的感谢、认可、轻微感叹和简短感想，不强制每条作独到分析或延伸。DeepSeek每次根据正文生成，没有固定评论池，也不提供成品例句供它套用；不能保证不同文章的短评绝不相似。
独立复核检查原文依据、相关性、内容范围、自然程度和反馈对象是否具体，不再以“缺少独到观点”拒绝自然短评。空泛感谢、无依据夸大或编造亲历仍不通过。全文读取、同篇核对、每天发表次数和本人验证规则继续保留。

用户已拒绝固定短句，旧方案不启用。每天九点清单已含观点，共八项；运动任务不加入。
已发表或结果不明的文章保留标题历史，后续避免在同一篇下反复留言。
详见docs/发表观点流程与验收-20261017.md。

订阅
每订阅一个返回积分页读分，达到2分停止新增；本轮试过的账号不重复点。
结束后从“我的→订阅”取消本机新增关注，保留用户原有关注。
每个账号只记录完整订阅并取消的次数、轮次和待取消状态，保存在config/subscriptions.sqlite3。
确认订阅并取消成功才计一次；验证中断、未关注成功不增加次数。
取消后不再返回积分页重复核分，采用用户已确认的取消不扣分行为。
可扫描分类走完一轮后，下次开始新一轮；每次尝试有上限，不无限循环。
真实访问验证仍需本人处理。实机验收结果和每日清单是否启用见docs/订阅流程与验收.md。

答题与验证
文章和视频不调用 DeepSeek；答题使用原有 DeepSeek 官网密钥。
密钥已由当前 Windows 用户加密保存，不需要重新填写。
需要修改时使用“配置答题密钥.cmd”或网页上的配置链接。
每日答题保留选择、填空和点选填空；趣味保留单人、双人和四人模式。
趣味按平台当天计分入口执行，不保证指定某种模式。
真实访问验证需要本人在 MuMu 完成。
手动运行遇真实验证或登录会保留任务；本人处理后，正常页面恢复即自动继续，无需再次执行。
每天定时遇真实验证或登录，每次最多等候10分钟；本人处理后自动继续，超时才结束并报告待处理项目。
网络错误最多重试一次；普通故障记录原因，保留已完成积分。
程序不能保证验证码永远不出现，也不能保证账号不会受到平台处罚。

检查与文件
“自检MaaXuexi.cmd”检查回归、启动配置和设备连接，不执行学习任务。

scripts：启动、停止、定时和自检入口。
resource：识别模型与图片，.venv：运行环境，均为运行必需。
page：统一控制网页。config：当前配置、加密密钥和最近结果。
logs：近期日志。tests：功能回归。docs：当前收尾与验收记录。

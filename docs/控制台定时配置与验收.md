# 控制台定时配置

版本：local-20261018.22。修改前Git检查点：cef083a。

在原有控制台的“每日定时”卡片设置。两个圆圈为单选：固定时间默认09:00，随机时间段默认08:00～09:00；初始选择随机时间段。时间统一为北京时间。再次打开读取已保存的设置，不重置为默认值。

- **保存定时**：保存时间设置。定时使用任务清单卡片中已经保存的每日任务清单。
- **立即执行**：立即运行该每日任务清单一次；不改变下次自动计划。已有任务运行时不重复启动。
- 在时间段内保存（例如07:32保存07:00～08:00），立即执行一次，下一次自动时刻从明天开始。固定时间保存时恰好处于所选分钟，也立即执行。仅切换或填写、尚未保存不会触发。
- 开始时间必须早于结束时间，目前设置同一天内的时间段；不支持跨午夜。
- 显示Windows实际下次时刻与逐秒倒计时。随机时刻每日只抽取一次，刷新页面不重新抽取；编辑过程中后台刷新不覆盖未保存输入。
- 电脑需要开机、登录Windows、未休眠且联网。沿用已批准的错过后恢复自动补跑，补跑可能超出设置时间段。关闭网页不停止后台或Windows定时。
- 时间随机仅表示启动时间更灵活，不代表免验证或降低封号概率；平台验证仍由本人完成。

## 实现

原隐藏启动动作、Windows用户身份、IgnoreNew和电源设置保留。后台保存选项于config/local-schedule.json，选定的具体时刻交给现有Windows日触发器。每日隐藏启动器在开始学习前，为下一天选定并保存具体时刻，因此学习或网络中断也不妨碍安排下一天。Windows原生RandomDelay不再二次随机。没有要求浏览器保持打开的计时器，也没有常驻每分钟轮询进程。

固定与随机两种模式共用同一条Windows任务，避免两种模式同时执行。读写用进程间锁串行，配置文件原子替换；Windows更新失败不会覆盖上一次保存的选项。

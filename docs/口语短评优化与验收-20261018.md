# 口语短评优化与验收

版本：local-20261018.19；修改前检查点：2c08aa9。用户要求更像读完后随口说出的反应，有一点惊讶、收获感，允许“学到了学到了”“长知识了”这样的语气。

## 实现

- 生成目标改为具体小发现和口语反应，不给每条评论强加“挺实用”“讲得挺清楚”等评语尾巴，也不强求延伸分析。
- 允许适度叠词、语气词、末尾单个感叹号，也可用句号或不加末尾标点。表达惊喜和收获时优先自然使用感叹号。
- 保留按完整正文生成与独立审核。情绪表达不等于编造经历，审核不把有情绪一律判成不客观；同时继续核对原文条件、推测与结论范围。
- 不使用固定评论库，不直接套整条成品评论。提示中只有用户希望的语气说明与短语示意；不能保证常用句式永不重复。
- 原20字上限两轮都拒绝了正常的一句话，现改为8～28个汉字，以10～20字为主。API显示的限制和日志同步更新。
- 较长评论在输入框或已发表列表换成两行时，可合并相邻、左侧对齐的两行核对完整原文。允许 OCR 将全角感叹号识别成半角；不忽略漏字、改字、缺失标点或拼接远处文字。
- 原文范围、全文读取、同篇核对、发表次数、订阅库、九点清单和本人验证行为保留。

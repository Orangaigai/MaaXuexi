## 已实现

1. 普通选择题的提示比较改为保留运算符、百分号、单位分隔和上下标。仅统一全角ASCII、空白及明确等价的句子标点，不再把5+3与5-3、ms与m/s、m²与m2当同一文本。即使用户开启旧极速开关，严格提示失败的选择题也不会落入旧模糊猜测分支，沿用模型判断。点选词块现有路径保持。
2. 普通填空先保留已有红字长度直填路径。无法直接用红字时，额外读取完整提示段落；仅在单个相邻输入格组、完整题干、空格长度和前后文都能唯一对应时直接填写原文。不猜最短差异、不按局部相似度补词。多个独立输入框、OCR整行跨过空位无法准确定位、题干缺失或多个可能答案时，保持原模型路径。本次没有新增独立多输入框的填入适配，不能宣称所有多空题已覆盖。
3. 在原RunReport与日志上增加诊断：截图与OCR分别计时；模型请求计时包含当前请求中已有的有限网络处理；每日提示、答案判断、填写、页面响应有阶段耗时；本人等待单列。上级阶段包含下级耗时，不能把所有字段相加当总用时。缺失项不冒充零耗时。
4. 每日收尾沿用现有页面变化记录，新增可校验哈希的关键画面索引，每轮最多24张。可用scripts/Replay-DailyTrace.py检查已保存的页面识别，--native-ocr选项会重新读取PNG。离线回放不连接ADB、不点击、不请求模型，也不等于真实提交和验证后积分验收。

文章的颜色已读识别、本轮去重、分批核分照旧；没有新增阅读历史数据库。九点八项清单、顺序与本人验证规则保持。没有引入通用AI操作代理、题库或额外页面重试。

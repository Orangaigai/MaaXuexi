# 每日文字分流与模型对比（local-20261018.1）

本次参考 [ScreenQA](https://github.com/Thedan-1/ScreenQA-ocr-quiz-solver) 的文字/视觉路径、[Promptfoo](https://www.promptfoo.dev/docs/configuration/expected-outputs/deterministic/) 的同题答案与耗时评测方法。没有引入这两个项目的运行服务或新依赖。

## 自动执行中的变化

1. 原有提示原文匹配继续优先，能直接确定答案时不调用模型，也不额外读取完整提示。
2. 需要模型的普通单选、多选，只有单屏可见题型标题、完整选项标签、出题信息和提示入口，且题干、选项和提示均完整、没有图形依赖时，才发送文字。
3. 选项从整屏 OCR 读取全部行，保留算式、单位、上下标和否定词。完整多行选项也用于提示匹配，避免只拿第一行误当完整选项。
4. 题面滚动过、选项缺失、提示到底部被截断、图形证据或无法确认完整时，保留原来的完整题面/提示图片。普通填空、点选填空继续使用现有提示直解和图片兜底，不同时大改输入行为。
5. 原有每日完成、访问验证、结果和自动返回流程保留，八项任务顺序与九点计划保留。

这不是给题干固定裁一个小框；完整图片一直保留。新增的图形检查更严格，但只用于决定每日普通选择题能否走文字路径，原趣味/对战的默认判断阈值保留。

## 模型对比工具

工具：`scripts/Compare-QuizModels.py`，样本：`tests/fixtures/model-eval/cases.json`。

使用安装目录中的现有 Python：

```powershell
& '.\.venv\Scripts\python.exe' -B '.\scripts\Compare-QuizModels.py'
& '.\.venv\Scripts\python.exe' -B '.\scripts\Compare-QuizModels.py' --run --models deepseek-flash deepseek-v4-pro --max-calls 8
```

第一条仅校验样本，无模型请求。第二条会产生官方 API 消耗，比较两个模型和文字/图片两条路径，共八次请求。工具不会操控安卓、开始积分任务、换运行模型或进入每天清单。当前工具使用现有 DeepSeek 官网账号，只向固定官方端点发密钥；不把该密钥转发给其他服务商。

每题保留独立答案依据及文件哈希，反馈图单独存放，不作为该题的模型输入。记录答对、限时内答对、失败、普通和较慢请求耗时、真实返回模型名及 token 消耗。应用不缓存答案；服务商前缀缓存情况按响应原样记录。可通过三项 `--*-price` 参数按提供的最新单价估算费用，未提供单价时费用为未知，不写成零。

当前只有两道已核实的历史题：一道有完整应用提示，一道有平台绿色正确项。它们用于检查链路和初步比较，不能当成广泛题型的准确率榜单；不是日常查答案题库。

## 本轮验证

- 全部离线回归：493 项通过，包括新增的完整/跨屏/缺项/多行选项/图形/提示截断、HTTP 实际输入结构、异常响应、评测答案来源、费用口径和失败计数检查。
- 原生 Maa OCR：真实每日题面与提示可形成完整文字输入；同题原文提示仍能直接确定答案。历史完成、访问验证、结果和答题中心四个阶段重新识别通过。
- 官方接口总计 12 次、无自动重试：当前 `deepseek-flash` 两题各两条路径、两轮，共八次，均取得正确答案；候选 `deepseek-v4-pro` 四次，三次取得正确答案，一次图片请求未取得符合确定性/格式要求的可用答案。

| 模型和样例 | 文字请求 | 图片请求 |
|---|---:|---:|
| 当前模型，每日题，两次中位数 | 1.204 秒 | 1.524 秒 |
| 当前模型，历史对战题，两次中位数 | 0.766 秒 | 1.156 秒 |
| Pro，每日题，各一次 | 1.375 秒 | 1.734 秒，答案未采纳 |
| Pro，历史对战题，各一次 | 1.250 秒 | 1.437 秒 |

请求耗时包含评测输入准备和接口返回，不是整轮任务耗时；日常新增完整提示 OCR 的耗时需另计，本轮历史提示原生 OCR 为约 0.102 秒。那道每日题在正常执行时会被现有提示规则直接解决，评测仅单独比较需要模型时的接口路径。不能说所有题都提速同样比例，也不能把重复请求当成不同题目。

保留当前模型。小样本没有支持换到 Pro 的证据，也没有测试其他服务商或 Jev，不作全市场最快最准结论。

## 纯图片选项的处理范围

参考 [学习通图片题工具](https://github.com/zenghaolinz/chaoxing-learning-super-tool) 的题干/选项图片收集思路，已经核对本机解析器边界：对战选项只含图片、没有可读文字时，当前解析器仍可能提前返回未识别。本轮没有可用的真实布局样本，暂待实际题面验收，未添加推测坐标或模板。现有普通图题与完整图片请求继续保留。

## 数据与验收边界

不增加文章跨重启历史库，不增加新积分项目。密钥、模拟器配置、订阅与观点数据库、发言规则、八项清单保持原文件内容。此次没有在 App 中重新答新题或发表观点，因此真实新题的端到端得分验收仍待自然出现，不能以历史回放代替。

安装和备份信息以 `config/installation.json` 的 `daily_text_routing` 字段为准；核验日志放在 `logs/text-routing-20261018`。本次本地研究与修改过程未发布远程仓库。

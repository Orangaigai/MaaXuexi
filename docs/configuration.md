# 配置说明

新安装只启用基础任务清单、保持手动执行，发表观点默认关闭。已有安装保留用户实际配置；更新不会替你重置任务和时间。

## 模拟器

实际文件为 `config/emulator.json`，安装程序会创建。可对照 [emulator.example.json](../config/emulator.example.json)：

| 字段 | 含义 |
| --- | --- |
| `mumu_cli` | 本机 `MuMuManager.exe` 完整路径 |
| `adb_path` | 同一 MuMu 安装中的 `adb.exe` 完整路径 |
| `vm_index` | MuMu 实例编号，通常从0开始 |

使用 JSON 时，路径可用 `/`，或将反斜杠写作 `\\`。运行时实际 ADB 地址由 MuMu 查询，不需要把示例端口写死。

## DeepSeek

基础任务不需要 API 密钥。每日答题、趣味答题和观点生成需要 DeepSeek 官方服务，项目沿用 `deepseek-flash`，不要求部署本地模型。

1. 在“设置 → 答题服务”打开“配置密钥”，选择“还没有，查看指引”。
2. 登录 [DeepSeek 官方 API 平台](https://platform.deepseek.com/)，检查 API 余额，按需小额充值。聊天产品的会员不等同于 API 余额。
3. 在 [API Keys](https://platform.deepseek.com/api_keys) 创建自己的密钥。
4. 回到本机配置页，在密码框粘贴密钥并点“保存并验证”。此操作会进行一次图片接口测试并产生少量费用。

验证通过表示本次请求成功，不保证服务此后始终在线。常见错误含义见[常见问题](troubleshooting.md#deepseek-未通过验证)。

密钥保存在 `config/deepseek-key.dpapi`，由当前 Windows 用户加密；网页不回显。不要把密钥贴到聊天、Issue、截图或 README 中。

## 清单与定时

任务选择在控制台管理。点击“保存所选任务”后，下次定时执行使用保存清单；点击“立即执行”只运行当前勾选内容，不自动替换保存清单。“保存基础任务”会保存登录、文章、视听、本地频道四项。

基础任务固定优先，其余四项可在任务清单拖动或用箭头排序。`local-task-plan.json`的`task_order`保存完整四项顺序，包括暂未勾选的项目；`tasklist`只保存选中的任务。建议通过控制台编辑，两者会一起保存。旧配置未含`task_order`时沿用每日答题、订阅、发表观点、趣味答题的默认顺序，读取不会改写原文件。排序不改变公开发言授权。

“定时自动执行”支持时间点、时间段；时间按北京时间。初始时间段为08:00～09:00，时间点为09:00。实际启用状态以 Windows 计划为准，单靠 JSON 文件不代表计划已生效。

每天的随机时刻选定后不会因网页刷新重抽。保存时正处在所设时段内，会立即发起一次保存清单的执行。恢复后可补跑错过的计划，补跑可能超出原时段。

错过计划且今天还未启动时，登录 Windows、网络连接恢复或睡眠唤醒会自动检查补跑，无需先打开软件。联网就绪后沿用原任务清单执行；未到时间、手动模式、今天已启动过均跳过。短暂断网时等待联网，不提前打开网页或模拟器，也不重排明天的计划。网络事件依赖 Windows 默认启用的 `Microsoft-Windows-NetworkProfile/Operational` 日志；原计划的延迟补跑仍保留。验证中断后的补做仍由控制台“继续执行”发起，不因网络变化反复尝试。

## 单人挑战题量

在“设置 → 单人挑战”选择档位，配置独立保存在 `config/challenge-preferences.json`；[示例文件](../config/challenge-preferences.example.json)只含档位与题数上限，不覆盖其他设置。`profile` 支持 `beginner`、`practiced`、`knowledgeable`、`adept`、`master`，`limit` 为 20～100 的整数，默认 50。界面显示的是计划目标分布的均值，不是实际得分保证；提前答错时正常结算，实际平台计分最低要求优先。

## 公开发言

**这个功能会以你的账号公开发布内容，首次安装默认不启用。** 并非只生成本地草稿。

若需要使用，请先阅读以下实际规则，然后将 `config/comment-policy.json` 中的 `enabled` 改为 `true`，重启或刷新控制台，再手动选择发表观点。配置格式见 [comment-policy.example.json](../config/comment-policy.example.json)。不要扩大 `scope` 或改写模式来绕开范围校验。

- 仅在科普中国/生活百科范围内读完文字内容，核对同篇内容，再生成三条短评候选并进行模型复核。视频页只使用完整文字简介，不猜测画面或声称已观看。
- 正文不足或范围不符时，返回原列表继续选文；单轮最多检查八篇，最多为三篇合格文字生成短评。实际选文和生成次数可在日志中查看。
- 完整短文同样可用，不以80字作为门槛。是否适合评论由可引用的具体内容和独立复核判断；文字未读完整、只有观看引导或没有事实依据时跳过。审核通过后才返回篇首核对身份，具体未通过项保存在本轮报告和日志中。
- 只从合格项里选择一条，8～28字，避免套固定话术、编造亲历或扩大正文结论；仍可能判断失误。
- 表达示例只帮助模型学习语气，不作为成品话术选择；候选可用一句或两小句。独立复核仍检查六项事实与范围条件，通过后优先选择自然、贴题且少重复的内容，不增加请求轮数。
- 无人值守每天最多一次发表尝试；本人发起可补验，每轮只提交一次；满分跳过。
- 记录已尝试文章；提交后结果不明不追加发布。真实验证仍需要本人完成。

已有安装的授权不会因本次文档整理被取消。关闭功能时，先结束当前任务，再设 `enabled=false`，从保存清单中取消发表观点。

## 订阅记录

`config/subscriptions.sqlite3` 记录本程序识别的订阅/取消次数、轮次和待清理状态。每次先核分，再清理本机新增关注；保留用户原有关注。完整订阅并取消后才计一次，不以某账号是否加分另建分类。

保留该数据库，不要每天清空。平台可能不为重复订阅计分，取消也不保证以后重新计分；程序不承诺某个回访周期必然有效。

## 控制台浏览器数据

专用浏览器数据使用 `runtime/control-browser`，与任务配置、积分数据库和密钥分开保存，不提交公开仓库。旧安装的 `config/control-browser` 会在专用浏览器关闭、能够确认没有进程使用时整目录原子迁移；不会清空或合并浏览器数据。

浏览器占用、进程无法核实、移动失败或新旧目录同时存在时，会保留并沿用旧路径。不要为了清理手动删除任一目录；先关闭专用控制台再重新启动，或保留两个目录并按日志排查。重定向目录会拒绝迁移，项目不会沿链接移动其他目录。

## 数据与费用

每日积分存放于`config/points-history.sqlite3`；自动关闭开关存放于`config/completion-options.json`，建议从控制台直接修改。两者都只留在本机，不提交公开仓库。积分记录、日历和自动关闭不调用模型，不产生API费用。

| 数据 | 去向与用途 |
| --- | --- |
| 学习账号登录态 | 留在 MuMu/App，不提交源码仓库 |
| DeepSeek 密钥 | 本机 DPAPI 加密；请求时发送给官方 API |
| 题目、提示或截图 | 需要模型时发往官方 DeepSeek；文字题优先发送完整文本，图片题保留图像 |
| 科普文章全文、短评候选 | 开启观点功能后用于生成与复核 |
| 日志、结果、运行截图 | 本机 `logs` 与 `config`；分享前检查并打码 |

API 按实际 token 和当期价格计费，参见 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。项目没有固定包月费用，模型请求也不是免费的。基础任务、本机环境检查和离线回归不调用付费模型。

## 控制台运行环境

顶部显示 DeepSeek 余额、学习强国官网连接和模拟器连接，可手动刷新。余额由后端读取[官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)，不发送题目或调用模型；自动检查间隔约一分钟，浏览器隐藏时停止轮询。网络与余额失败分别展示，查不到不记成零。官网可达只表示电脑能连接官网，不能保证模拟器内每个网页都能加载。

- 平台返回可用且余额不少于 1 元（美元账户为 0.20 美元）显示正常；低于此值只提醒，不禁止任务。这是本工具的提醒线，并非平台规定或能完成多少天的保证。
- 零余额、平台明确不可用、密钥失效、查询失败分别提示，充值后点击刷新；API 402 的处理依据[官方错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。
- 参考 [OpenUsage](https://github.com/janekbaraniewski/openusage/blob/main/docs/site/docs/providers/deepseek.md) 和 [DSH 余额插件](https://github.com/kyya/dsh-deepseek-balance) 的后端缓存与状态指示思路，不引入其框架或依赖，密钥不发送到浏览器。

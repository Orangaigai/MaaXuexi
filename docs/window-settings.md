# 窗口显示与通知

在控制台右上角点击 **设置**，进入本机设置页。显示方式和通知开关保存后立即生效；模拟器未启动时，下一次连接自动应用。修改设置不会启动学习任务，也不调用模型。

## 推荐设置

默认选择 **后台运行**，开启 **需要本人处理时显示一次**，保留桌面通知，关闭 **定时启动时打开进度网页**。

平时模拟器最小化到任务栏。检测到需要本人处理的页面，程序暂停并显示模拟器一次，随即解除置顶；你点击其他窗口后，模拟器可以被覆盖，不会定时抢回前台。本人验证完成、程序确认恢复后，重新最小化并继续任务。主动点击控制台“暂停”不会弹出模拟器。

验证页面仍可能由平台自行超时。窗口提醒不延长验证有效期，不自动处理验证。来不及处理时，之后从控制台继续未完成任务。

## 显示方式

| 选项 | 行为 |
| --- | --- |
| 后台运行 | 最小化到任务栏，截图、识别和输入继续通过模拟器接口进行 |
| 窗口置底 | 显示窗口并放到其他窗口下面，便于保留画面又减少遮挡 |
| 正常窗口 | 解除程序设置的置顶，由用户切换窗口，不主动恢复或抢前台 |
| 始终置顶 | 保持模拟器在普通窗口上方，适合观察任务；本人处理阶段暂时解除，处理后恢复 |

“需要本人处理时显示一次”独立于上述四种方式，也独立于 Windows 桌面通知。关闭它后，程序仍会暂停、记录状态，但不为验证主动显示窗口。设置页“显示模拟器”可以手动显示一次，不修改保存的偏好。

仅针对 `config/emulator.json` 指定的 MuMu 实例操作。每次使用 CLI 返回的主窗口句柄，核对其顶层窗口及进程归属；不按窗口标题模糊操作其它软件，不向桌面发送鼠标或键盘事件。

MuMu 本身首次冷启动可能短暂展示厂商窗口。脚本不再调用强制显示命令，设备就绪后应用显示偏好。关闭模拟器窗口、退出 Android、电脑睡眠、锁屏或不同远程会话不等于这里的后台模式，不能据此保证任务正常运行。

## 通知、收尾与其他设置

- **Windows 桌面通知**：控制本人处理、设备异常及未完成任务的系统通知。关闭后仍保存日志、积分和待处理结果，不改变自动暂停及恢复行为。桌面通知是否真正显示也受 Windows 通知设置、勿扰模式影响。
- **定时启动时打开进度网页**：默认关闭，避免计划启动时自动弹浏览器。手动打开项目启动入口仍会显示控制台。
- **完成后关闭模拟器 / 关闭网页控制台**：两个独立开关，即时保存；全部所选任务完成并保存记录后才关闭勾选的部分。仅关闭模拟器时后台和控制台保留，关闭控制台时同时退出后台；未完成时保留现场。
- 关闭模拟器时只停止本脚本配置的实例。若还有其他 MuMu 实例正在运行，保留那些实例和 MuMu 主程序；全部实例均已停止才请求主程序正常退出。仅创建但未启动的实例不影响退出，无法核实状态时保留主程序，不强制杀进程。
- **积分记录**：首次跳过历史导入后，可在设置中重新选择“仅导入每日积分”或“导入积分及明细”；含明细仍需确认预计耗时。
- **答题服务**：链接至原 DeepSeek 密钥配置与教程，不改变接口、模型和密钥存储。

显示与通知偏好保存在私有 `config/local-preferences.json`，缺失时使用默认值，更新源码不会覆盖。发布示例为 `config/local-preferences.example.json`。

## 截图耗时自检

设置 → 帮助与排查 → 运行环境自检，会显示最近一次成功截图的实际毫秒值及采样时间。该值只包括取图，不包括OCR或模型推理，也不代表所有题目的响应速度。尚未执行取图时显示“暂无截图样本”；自检不会额外取图或启动任务。

## 依据与实际验证

设计参考 [scrcpy 窗口选项](https://github.com/Genymobile/scrcpy/blob/master/doc/window.md) 将置顶和普通显示区分开，使用 [Windows ShowWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow) 的不激活显示方式及 [SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) 的不激活层级调整。没有调用 `SetForegroundWindow` 或模拟按键抢焦点。

[MaaFramework 控制方式](https://maafw.com/docs/2.4-ControlMethods/) 区分模拟器专用截图、ADB 输入和桌面控制。项目沿用 MuMu 专用截图与 ADB 触控，未切换到桌面截图。[OnmyojiAuto 的发布说明](https://github.com/RMA-MUN/OnmyojiAuto/releases) 也包含完整 MuMu 后台支持。社区 [MaaEnd 后台控制器反馈](https://github.com/MaaEnd/MaaEnd/issues/2616) 和 [AzurLaneAutoScript 模拟器说明](https://github.com/LmeSzinc/AzurLaneAutoScript/wiki/Emulator_cn) 说明不同捕获方式和模拟器选项不能混为一谈，需要在实际设备上验证。

当前 Windows/MuMu 15 设备已实测：窗口置底和最小化时均可通过原控制器读取完整 720×1280 画面、本机 OCR 识别 Android 设置列表并滑动到下一屏，截图内容实际更新；前台窗口未变化。提醒显示后不保留置顶。此项实测不产生答题、订阅或公开发言，不替代本人验证。

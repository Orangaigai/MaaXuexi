# 使用指南

## 第一次手动执行

1. 双击启动MaaXuexi.cmd，等待模拟器连接和控制台加载。
2. 在任务清单勾选需要的项目。暂时离开时优先选择基础任务，但登录和平台变化仍可能要求本人处理。
3. 点击“立即执行”。运行状态、每项实际积分和结果会在页面更新。

“立即执行”使用当前勾选与排序，只运行本次任务；“保存所选任务”才会把清单和顺序保存给下次使用。“保存基础任务”直接保存四项基础任务，不启动学习，也不清空其他任务已排好的顺序。

控制台上方显示运行状态、执行安排和下次启动倒计时；下方是任务清单、每日积分和可展开的运行日志。具体定时编辑、窗口通知、自动关闭、密钥和环境自检集中在右上角“设置”。任务标题旁显示已选数量和保存状态；尚未保存的修改可点“还原”。[页面分工说明](console-layout.md)

## 执行顺序

只执行勾选的项目。基础任务始终按“登录 → 选读文章 → 视听学习 → 本地频道”优先执行；其余四项可自行调整。初始默认顺序为：

**登录 → 选读文章 → 视听学习 → 本地频道 → 每日答题 → 订阅 → 发表观点 → 趣味答题**。

在“可能需本人验证”分组拖动手柄，或使用上下箭头提前、延后；键盘也可在对应任务上按Alt+↑/↓。数字表示这四项之间的先后，未勾选项不执行。运行中不能修改；未保存的改动可还原。

取消勾选再重新选择时保留原位置；保存后的安排用于下次手动及定时执行。中断后“继续执行”沿用原轮顺序并重新核分，不被后来修改的清单替换。旧完整验收入口也保持基础任务优先。

基础任务通常较少遇到验证，但登录、平台变化等仍可能需要本人处理。程序不预测本轮验证，也不为寻找免验证入口反复进入任务。分数、当日趣味模式与平台页面以实际读取为准。

文章按缺额分批核分，视频核对真实播放进度；满分会停止该项。趣味答题按平台当日提供的入口执行，不保证用户能任意指定单人、双人或四人计分模式。

每日多选先核对完整空格与全部选项：例如三空三选时直接全选，两空三选时继续看提示。识别的是题干下划线组，行首完整空格结合上一行文字判断；跨行两段、重复使用选项或数量无法确认时保留提示路径。选择题复用完整页面 OCR，图片及长题不会为提速而截掉内容。提示弹层就绪后才读取红字，无法严格匹配时仍调用原 DeepSeek 服务。

每日多选在确认完整空格数与全部选项数相同时直接全选；空格跨行、数量不符或无法确认时继续查看提示。长图片题会保留重叠的完整截图，翻到提示后收齐选项；选择时向上查找，每个答案只点一次。单人挑战每局计划答对 3～15 题，3～9 题更常见；不低于实际读取的计分要求，提前答错即结算并核分，不重开刷题。随机题数会增加部分作答时间与模型调用，不保证减少平台验证。

## 暂停、中止与继续

| 操作 | 行为 |
| --- | --- |
| 暂停 | 等当前操作结束后暂停当前任务 |
| 继续执行 | 活任务恢复原轮；中断任务重新核分并补做原清单未完成项 |
| 中止任务 | 结束本轮；已确认的积分和记录保留 |
| 关闭网页 | 后台继续运行，重新打开本机网址可看进度 |
| 停止MaaXuexi.cmd | 关闭属于本安装的后台进程 |

运行区按实际报告显示已确认的任务项数及本轮时间；该进度表示任务项数，不是预计耗时。连接中断会明确显示重连提示，正常自动关闭另行标明。

有未完成任务时，“继续执行”比“立即执行”更醒目。想接着原清单做时优先使用继续，不必多次新建执行。

## 需要本人验证时

程序不会拖滑块或绕过平台访问验证。请在 MuMu 本人完成验证并保留后续页面；识别到正常页面后会自动继续，不需要手动答题、返回或再点网页执行。

定时运行每次最多等候10分钟；平台验证自身可能更早过期。任务已结束或页面已退回时，回来在控制台点“继续执行”，以实际识别和核分结果为准。不要把“网络开小差”一律认作本人验证已通过。

明确网络错误按原规则最多点一次重试；不能确认正常页面时停止并报告。不会为规避验证无限重进、重复提交或重复匹配。

## 设置每天自动执行

1. 先选择并保存任务清单。
2. 打开“设置 → 执行与定时”，切换到“定时自动执行”，选择“时间点”或“时间段”。
3. 修改时间并点“保存定时”，查看保存提示、下次时刻和倒计时。

切换执行方式立即生效；时间编辑需保存。切回手动会关闭未来定时启动，已运行任务不被终止。保存时处在设置时段内会立即运行一次，所以在场修改时留意当前时间。

电脑须开机、登录安装时的 Windows 用户、未休眠且联网；仅联网不够。项目不保证自动唤醒电脑。错过后恢复可补跑，网页不用一直开着。

## 查看结果和自检

### 每日积分

控制台“每日积分”按月显示日期和已核实分数。点击日期，在右侧查看各项积分、任务状态及未完成原因；用月份箭头查看过去记录，“回到本月”返回当前月份。记录按北京时间归档，同一天重复运行更新同一日快照，不把多次核分相加。

日期没有记录时不显示分数，实际核实为零才显示“0分”。部分任务或验证未完成会显示待处理；只核实了部分项目时，会注明已记录项目数，不推测其它积分。首次更新导入当前保留的运行报告；更早未保留的数据不补造。

首次使用积分日历时，有三种选择：

| 选择 | 导入内容与操作 |
| --- | --- |
| 导入积分及明细 | 每日总分和每笔积分来源；先展示读取方式、预计耗时及费用，点击“确认导入”才开始 |
| 仅导入每日积分 | 只读每日总分，通常约 1 分钟；不逐日翻阅明细 |
| 从今天开始记录 | 跳过历史导入，保留已有记录，今后正常记录 |

两种导入都连接已配置、已登录的模拟器，无需另外登录网站，不执行学习、订阅或发表任务。使用本机文字识别（OCR），**不调用 DeepSeek，API 费用为 0 元**；无需为导入配置模型密钥或充值。完整明细需要逐日翻阅，近 30 天首次预计约 8～15 分钟，实际随明细数量、设备和页面加载速度变化。读取时请勿操作模拟器，期间可能仍需本人处理平台登录或验证。

页面显示实际阶段、已处理日期及已核实笔数，提供取消；刷新或关闭网页不会另起一次导入。完成后自动刷新日历，部分记录未通过核对时明确提示，可重新导入补齐；已有且总分一致的往日明细会复用。取消不删除原记录，本轮尚未写入的读取结果不保存。已有历史补录的安装不重复显示首次提示。

读取入口为“我的 → 学习积分 → 右上角⋯ → 积分明细”，可查询范围以当前账号页面为准。当前使用本机 OCR 读取图表的日期和每日分数，正反两轮一致才保存；尚未接通 App 内部的原始历史接口。页面改变、日期不明或两轮不一致时不会猜测分数。导入按日期合并，重复导入不会累加同一天；未知日期保持空白，已核实零分保存为零。

历史导入采用“当日积分”，不采用可能扣除订阅等项目的“年度积分”。日历会标注“平台历史记录”；有明细时，点击日期查看来源汇总，展开“积分流水”可看原始项目、时间与分数。时间按手机页面精确到分钟，不补造秒数。没有明细时只显示总分，不推算各项分数、上限或完成状态，也不表示当日所有脚本任务均已完成。今天的分数另外从实际任务列表读取，旧观察不能覆盖较新的实时核分；平台范围外且本机未保留的数据不能凭总积分倒推。

后续设置页将提供“设置 → 积分记录 → 导入历史积分”，本次预留接口，不在日历工具栏长期放置按钮。设置页尚未上线时，跳过后可通过本机导入接口发起，开发用法见[模块说明](architecture.md#历史积分导入接口)。不要手工删除积分库来重现首次提示。导入与学习任务互斥，定时任务遇到正在导入时等待结束，不会同时操作模拟器；仅导入完成不触发学习任务的自动关闭。

积分记录保存在本机`config/points-history.sqlite3`，关闭程序和重启电脑不会丢失，也不会提交到GitHub。它是本项目核实到的记录，平台后来发生的变化需下次核分才能更新。

### 完成后自动关闭

“设置 → 运行收尾”提供两个独立开关：**完成后关闭模拟器**、**完成后关闭网页控制台**。新安装默认都开启；原来关闭总开关的用户继续保持两项关闭。全部所选任务完成、积分记录保存后倒计时30秒，仅关闭勾选的部分。只关闭模拟器时控制台和后台保留；只关闭控制台时模拟器保留，后台退出。倒计时可点“本次保持打开”，仅取消本轮收尾，不修改长期设置。

验证未完成、任务失败、积分记录保存失败或主动中止时不自动关闭，保留结果与处理现场。开始新任务会取消上一轮倒计时，避免误关新的执行。

以后启动使用独立控制台窗口，重复打开会优先使用已有窗口，只关闭本项目持有的窗口，不结束普通浏览器或其它模拟器实例。浏览器不支持独立窗口时会使用普通网页，此时需自行关闭该标签页。

当天已有完成报告时，重新启动控制台先用于查看记录，不额外启动模拟器；点击执行仍会自动准备设备。Windows定时计划独立于后台，次日到点会重新启动所需程序。自动关闭不会关闭电脑或取消次日定时设置。

当天已经启动过正式任务时，自动执行不会再重复启动；提前点击“立即执行”会让下次定时安排到明天。日期按北京时间划分，重启后台后仍有效。手动“继续执行”和再次手动执行仍可补做，已满分项会跳过；保存清单本身、被拒绝的启动、单组验收不占用当天执行次数。错过时段后的自动补跑仅在当天尚未启动过时进行。

### 运行结果与自检

任务结果统一显示在每日积分的日期详情中。“已满分”表示这次核实到了满分并跳过该项，不能当成这次重新完成了阅读、答题或发表。尚未读取到分数的任务显示“—”，仍保留执行状态和原因。

控制台底部“运行日志”和“设置 → 帮助与排查 → 运行环境自检”默认收起。自检只读、不收费、不启动学习；它的“已验证”是最近密钥测试结果，不代表此刻所有外部服务必然可用。

## 后台与通知

右上角“设置”可选择后台运行、窗口置底、正常窗口或始终置顶。默认后台运行，需要本人处理时只显示一次，验证通过后恢复后台；桌面通知可独立关闭。定时执行默认不弹浏览器，手动打开启动入口仍显示控制台。[完整说明](window-settings.md)

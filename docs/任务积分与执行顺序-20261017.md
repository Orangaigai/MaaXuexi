## 排序决定

登录为前置条件，先确认账号可用。随后依次为：

**选读文章12 → 视听学习12 → 本地频道1 → 趣味答题最高10 → 订阅2 → 发表观点1 → 每日答题5。**

第一组通常无需验证的任务先做，合计含登录26分；第二组内按已核实上限10、2、1排序；本机模拟器频繁验证的每日答题放最后。因此本次实际改变是将趣味答题提前到订阅、观点之前，其他相对顺序保留。网页显示、后端任务归一化、默认清单和已保存九点清单同时更新。

此排序严格遵循用户“先验证分组、同组分数高优先”的要求，但存在取舍：趣味一旦触发验证，后面的订阅与观点也会等待，**不能宣称比先做订阅和观点更能保住无人值守积分**。如果单纯以验证前完成尽可能多项目为目标，旧顺序也有合理性；本次不暗中替换用户已指定的优先规则。

真实验证继续原地暂停，等待本人完成并自动观察恢复；定时运行每次最多等待10分钟，超时报告未完成项。不会通过退出、重进、自动解验证来提高所谓免验证率。若启动时本来留有真实验证，必须先处理该现场；排序不能保证越过前置验证去做其他项目。

# 执行方式与任务面板

适用版本：local-20261018.24。

## 使用

任务区按顺序提供“保存所选任务”“保存基础任务”“立即执行”。前两项保存清单，不会立即开始任务；保存基础任务会保存并选中登录、选读文章、视听学习、本地频道四项。立即执行只运行当前勾选项。选择手动或自动都能随时点击立即执行。

执行方式使用两项互斥单选卡片，切换立即生效：

- 手动执行：关闭本机 Windows 定时任务，收起时间设置。已有正在运行的学习任务继续；需要中止时使用运行状态中的中止按钮。
- 定时自动执行：启用 Windows 定时任务，展开时间设置与下次执行倒计时。恢复已保存的时间选择；切换本身不补跑当前时段。

自动执行内的时间选择改名为“时间点”和“时间段”。时间段旁用小型“推荐”标签说明建议，不强制改变已保存选项，也不将推荐解释为防封保证。时间段仍每天随机选择一次启动时刻；新安装默认08:00～09:00，时间点默认09:00。

修改具体时间后点击保存定时生效；保留此前保存于当前时段内会立即执行一次的行为。未保存的时间修改在模式切换、背景刷新期间保留；刷新网页则以已保存设置为准。

原顶部的长计划及电脑条件移至自动执行区域。删除“仅选基础任务”单独说明行和观点已启用的说明行，观点授权判断仍保留。立即执行只保留任务区一处，旧的定时立即执行API留给已有调用方兼容使用。验证标记、任务先后顺序、本人验证后自动续跑、暂停与中断补做保持原行为。

关闭定时后，已排队的自动启动也会读取真实 Windows 禁用状态，正常结束，不重新启用定时、不提交学习任务。定时计划以 Windows 实际状态为准，不只保存网页显示状态。

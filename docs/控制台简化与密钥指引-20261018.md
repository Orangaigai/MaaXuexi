# 控制台简化、密钥指引与暂停续跑

适用版本：local-20261018.23。

## 页面使用

控制台保留原蓝白风格。原来的长段执行说明改为任务旁的验证标记和简短提示，日志默认折叠。具体实现、研究及验收资料留在文档中。

“保存任务”在前，保存每日定时使用的清单；“立即执行”在后，只执行当前勾选项。两组按钮与每日定时的保存、执行按钮对齐。仅选基础任务只改变勾选，不自动保存或启动。

DeepSeek 配置放在独立卡片中。未配置时显示明确入口；不配置也能先用基础任务。配置页先询问是否准备好密钥：已有密钥可直接填写，没有密钥则查看登录、充值、创建密钥、连接验证四页指引，可前后翻页或跳过。充值、登录和创建密钥由用户在官网完成。

API 按实际调用计费，短文本自动答题通常开销较少，但不保证固定日费或月费。页面建议按需小额试用并查看官方账单，不写死最低充值额、当前单价或不确定的官网按钮位置。只查看指引不会请求付费接口；主动保存并验证或验证当前密钥会产生一次接口调用。输入框不回显旧密钥，新输入提交后清空；继续使用本机 DPAPI 加密存储。

## 暂停与继续

- 手动暂停：在下一处可中断操作处暂停，不强行截断一次设备或接口请求。点击继续执行，恢复同一轮任务。
- 真实验证：沿用原有暂停与正常页面观察。本人在模拟器验证通过后自动继续，不需要点击网页继续；网页继续按钮不能解开仍未完成的验证。
- 任务已中断：继续执行取原运行报告的所选清单，重新核对实际积分，已满项目跳过，只补未完成项目。不会偷偷扩大为当前保存的每日清单。
- 已全部完成：不显示补做入口；需重跑时使用立即执行。
- 中止：结束当前任务，稍后可从原清单继续补做。

趣味答题、订阅、发表观点、每日答题标记“可能需验证”，顺序仍在基础任务之后。验证出现的条件由平台决定，登录和基础任务也不保证免验证。无人值守原来的十分钟等待上限继续保留；验证页面也可能先由平台超时返回。控制台不把这一过程宣传为规避风控，不循环重开验证、不自动解验证，也不承诺不会封号。

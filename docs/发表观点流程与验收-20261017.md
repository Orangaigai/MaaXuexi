# 发表观点：固定短句与验收

本次版本 local-20261017.15。运动任务按用户要求排除。

## 内容与范围

- 唯一候选短句：**认真学习，增长知识。**（8个汉字、2个标点）。
- 范围：**科普中国 → 生活百科**文章。正文未加载、入口不明确时不发表。
- 每天最多一次发布尝试，先核分，已满1分跳过。
- 不调用 DeepSeek 或其他模型写评论，不根据文章中的文字更改短句。
- 发布前分别读取输入框全文与本框的“发布”按钮，全文必须与固定短句一致。
- 用户确认具体文案和每日使用范围后，才可启用 config/comment-policy.json 并加入九点清单。当前未启用。
- 固定用语限制输出内容，但不能承诺所有语境下绝对正确、审核通过或必定获得积分。

## 执行流程

核分 → 检查文案授权及当日记录 → 首页频道菜单 → 科普中国 → 生活百科 → 已识别文章 → 等待正文 → 打开观点框 → 输入固定短句 → 核对全文与发布按钮 → 数据库先占用今日一次额度 → 点击发布一次 → 本人处理真实验证（如有） → 返回文章和推荐首页 → 重进积分页核分。

本地数据库 config/comments.sqlite3 按日期保留文章、固定文案、发表尝试和核分结果。点击超时、程序中断或积分未到账，当天再次运行也不重复发布。仅在积分页实际显示满分后记录 credited；“已输入”“已点击”均不等于已得分。

观点加入后的建议顺序为：登录、文章、视频、本地频道、订阅、发表观点、趣味答题、每日答题。当前保存的九点清单仍为原七项，发表观点留待具体文案确认。

## 已完成的验证

- 真机 MuMu 720×1280，学习强国2.74.0：程序自主进入科普中国/生活百科、打开《AI没有心，却让你动了心》、输入并识别完整短句及独立“发布”按钮。
- 首次测试发现新加载文章的输入栏可能忽略第一次点击；只对仍明确显示的输入栏补一次120毫秒短按，发布按钮绝不重复点击。
- 已关闭本次未发布草稿，自动返回推荐首页，再读取观点实际积分 **0/1**。没有把草稿测试当作得分验收。
- 413项离线回归通过，包含缺少确认、非法文案、额外文字、重复启动、发布中断、验证超时、平台积分上限变化、Windows数据库句柄关闭，以及原有答题、订阅和定时任务。
- **尚未验收：真实公开发表、服务端观点计分、观点发表后可能出现的验证及其恢复。** 必须在用户批准具体短句和使用范围后继续。
- 本次检查没有调用付费模型；原有密钥、订阅历史和定时任务数据保留。

参考过的开源实现：[LearnChinaHelper](https://github.com/gzhjic/LearnChinaHelper) 使用定位输入框、写入固定文本、点击发布的流程。它的旧版计分和多次评论逻辑没有照搬，本机以当前积分页“每个有效观点1分、每日上限1分”为准。

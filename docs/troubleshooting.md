# 常见问题

## 双击启动没有反应

确认解压了整个项目并完成首次安装。根目录应有 `.venv/Scripts/pythonw.exe`。启动过程的详细信息位于 `logs/launcher-*.log`，不要因为网页暂未出现就连续打开多个后台。

安装脚本找不到 Python 时，检查 `py -3.12 --version`，或按[安装指南](installation.md#用命令安装)明确指定 Python 路径。

## 端口8000被占用

先看是否已有本项目控制台。重复启动应复用本项目后台；脚本不会为了腾端口关闭无关程序。

确认是本安装的旧后台后，可运行停止MaaXuexi.cmd 再启动。如果是其他软件占用端口，需要自行处理该软件；不要把“占用”直接归因于断网。

## 模拟器停在桌面或广告页

检查 `config/emulator.json` 指向本机正确的 MuMuManager、ADB和实例。现有启动流程可识别确认过的模拟器桌面并启动应用；未识别的弹窗、登录或广告变化不保证自动通过。

保留现场，记录当前截图和日志提示。不要为排错随意改分辨率、字体缩放或频繁重装 App。应用识别画面应是720×1280竖屏。

## 任务执行方式或定时无法读取

初次安装需要创建项目专属 Windows 计划，即使目前只手动执行，也会以关闭状态保留计划。若使用了 `-SkipSchedule`，定时功能没有完成安装。

检查任务计划程序中 `MaaXuexi-Daily-0900` 的动作指向当前目录。另一个安装目录拥有该名称时，安装脚本会停止而不替换；处理方式见[更新与迁移](installation.md#更新与迁移)。

计划要求安装时的 Windows 用户已登录；电脑关机或休眠时不会照常操作模拟器。恢复补跑可能不在原时段内，不能仅凭网页倒计时证明系统实际运行过。

## DeepSeek 未通过验证

| 提示 | 先检查什么 |
| --- | --- |
| HTTP401 | 是否使用官网API Key，粘贴内容是否完整 |
| HTTP402 | API平台余额是否充足；聊天会员不等于API余额 |
| HTTP429 | 请求频率或账号限额，稍后再试 |
| 超时、连接失败 | 本机网络、代理路径和服务状态 |
| 已响应但图片结果异常 | 当前模型图片接口是否可用，查看完整测试提示 |

项目不会替你切换整台电脑的 VPN 或系统代理。关闭代理后仍可能是平台服务、验证过期或模拟器网络问题，不能只凭“网络错误”确定原因。

首页“已验证”是最近一次密钥测试的结果；本轮服务错误另留在任务结果中。不要反复保存密钥或连续付费测试来碰运气。

## “完成”按钮、访问验证和网络错误

三者是不同画面。“完成”应由每日收尾逻辑处理；访问验证需本人完成；网络错误只进行原有的有限重试。报告问题时请说明是否亲自验证并看到明确的通过提示，以及随后出现了哪一页。

如果验证已过期或任务已结束，保留当前页面并在控制台点“继续执行”。不要反复手动答新题、发布新评论或重开整轮来代替排错。

## 订阅或观点没有加分

以积分页实际值为准。平台可能判定重复订阅、无效观点或尚未结算；程序不会保证每次操作都加分。

保留订阅和观点数据库。删除数据库会丢失本机操作历史，可能造成重复尝试。观点默认关闭；启用方法及其公开发布行为见[配置说明](configuration.md#公开发言)。

## 查看诊断

先使用控制台底部“运行环境自检”，它免费、只读，不会重新做题。根目录自检MaaXuexi.cmd 还会执行离线回归，并要求实际设备和原自检所需配置可用；首次只配置基础任务、未配置DeepSeek时，优先使用网页自检，不把缺少密钥认作基础任务不可运行。

提交 Issue 前，提供版本、当前任务、复现步骤和打码截图。不要上传 `config`、完整 `logs`、模拟器数据目录或密钥。
